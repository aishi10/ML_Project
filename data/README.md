# Data

Place the two official UNSW-NB15 partition files here (they are not committed to the repo):

- `UNSW_NB15_training-set.csv` (175,341 rows)
- `UNSW_NB15_testing-set.csv` (82,332 rows)

Source: https://research.unsw.edu.au/projects/unsw-nb15-dataset
(look for the "training and testing sets" files; if the link has moved, search for "UNSW-NB15 dataset").
The dataset has its own usage terms. Cite Moustafa & Slay (2015) if you use it.
